# Copy
> Load when: writing UI text, titles, empty states, errors or page descriptions for a Szmelc web UI.

- Project UIs: English, plain and short (STE-style: one idea per sentence, active voice). szmelc.com skins: Polish first.
- Address the reader as "you", in the imperative. The UI never says "we" and never apologizes.
- Labels are sentence case. Wordmarks and section labels may be uppercase with letter spacing.
- Titles on skins follow the window contract: `NAME.exe — [Subtitle]` or `File.txt — Notepad`, with an em dash.
- Never write: "seamless", "effortless", "powerful", "modern solutions", feature-grid benefit copy, cookie legalese, or Lorem ipsum.
- Filler text is a joke in the skin's voice, never a placeholder like "[description here]".
- In-character numbers (`v6.66`, `65536K OK`) belong to skins only. Project UIs show real versions and dates.
- One line under the wordmark at most. If the page needs a paragraph to explain itself, the layout is wrong (`RULES/UX.md`).
